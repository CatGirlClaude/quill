# Plan 001: Quill MVP — Vertical Slice Implementation

**Goal**: Deliver an end-to-end singleplayer vertical slice where pressing a keybinding in-game opens a modern, non-pausing VS Code-style IDE (`QuillIdeScreen`) connected through `EditorBackend` to the active world's `datapacks/` folder, supporting file tree navigation/CRUD, quick scaffolding actions, extensible `data/minecraft` presets (`load` and `tick`), multi-tab `.mcfunction` editing, and instant datapack reload with visible status/error feedback.

## 1. Visual Design & Layout Specification (VS Code Dark+)

The IDE opens as a non-pausing screen (`isPauseScreen() == false`) rendered with `GuiGraphicsExtractor`. It can be toggled between docked/windowed mode (with a slight translucent margin showing the live game world around it, like Code Builder) or maximized mode.

## 2. Implementation Steps (Vertical Slice)

### Step 1: Backend Core, Security & Local Implementation (`src/main`)

**Objective**: Build the server-side/common foundation so all file and datapack operations are testable independent of the UI.

1. **`dev.catgirlclaude.quill.api.*`**:
   - Define `EditorBackend` interface and immutable records (`FileTreeNode`, `EntryKind`, `FileDocument`, `SaveResult`, `ReloadReport`, `ReloadDiagnostic`, `PresetDescriptor`).
2. **`dev.catgirlclaude.quill.security.*`**:
   - `EditorLimits` (file size <= 512 KB, path length <= 255, tree depth <= 16).
   - `PathSandbox` (anchors paths to `server.getWorldPath(LevelResource.DATAPACK_DIR)`, normalizes, blocks `..` and symlinks, enforces extension allowlist `.mcfunction`, `.json`, `.mcmeta`, `.txt`, `.md`, and performs atomic temp-file writes).
   - `EditorPermissionChecker` (verifies singleplayer owner or OP level >= 2).
3. **`dev.catgirlclaude.quill.reload.DatapackReloadCoordinator`**:
   - Runs on `MinecraftServer` thread: invokes `PackRepository.reload()`, auto-enables newly created directory datapacks (`file/<packName>`), calls `server.reloadResources(...)`, and captures any function/tag parse errors generated during the reload cycle into `List<ReloadDiagnostic>`.
4. **`dev.catgirlclaude.quill.backend.ServerEditorBackend`**:
   - Implements `EditorBackend` against a `MinecraftServer` instance using `PathSandbox` and `DatapackReloadCoordinator`.

**Commit checkpoint**: `feat(backend): add EditorBackend API, PathSandbox security, and local server backend`

---

### Step 2: Extensible Presets & Scaffolding Engine (`src/main`)

**Objective**: Support 1-click datapack/namespace/function scaffolding and resource-driven presets for `data/minecraft`.

1. **Datapack & Namespace Scaffolding (`DatapackScaffolder`)**:
   - `createDatapack(packName, description)`: Validates name, creates `<datapacks>/<packName>/pack.mcmeta` with `min_format: 121, max_format: 121` (per [docs/MC_NOTES.md](../docs/MC_NOTES.md)), and creates `<datapacks>/<packName>/data/`.
   - `createNamespace(packName, namespace)`: Validates `[a-z0-9_.-]`, creates `data/<namespace>/function/`.
   - `createFunction(packName, namespace, functionPath)`: Validates `[a-z0-9/._-]`, creates `data/<namespace>/function/<functionPath>.mcfunction` with a starter comment header.
2. **Resource-Driven Preset System (`PresetRegistry`)**:
   - Load preset definitions from `src/main/resources/assets/quill/presets/index.json` and template files under `src/main/resources/assets/quill/presets/templates/`.
   - Built-in presets for MVP:
     - `minecraft:load` — Creates or merges `"<namespace>:load"` into `data/minecraft/tags/function/load.json` and scaffolds `data/<namespace>/function/load.mcfunction` if absent.
     - `minecraft:tick` — Creates or merges `"<namespace>:tick"` into `data/minecraft/tags/function/tick.json` and scaffolds `data/<namespace>/function/tick.mcfunction` if absent.

**Commit checkpoint**: `feat(presets): implement datapack scaffolder and resource-driven load/tick presets`

---

### Step 3: Non-Pausing VS Code Shell & Keybinding (`src/client`)

**Objective**: Open the IDE in-game via a shortcut key without pausing the world, rendering the VS Code frame.

1. **`QuillKeyMappings`**:
   - Register `key.quill.open_ide` (default `K`, category `category.quill.general`) via `KeyMappingHelper.registerKeyMapping(...)`.
   - Handle client tick via `ClientTickEvents.END_CLIENT_TICK`: when pressed in a world, resolve `ClientEditorSession` (creating a `ServerEditorBackend` bound to `Minecraft.getInstance().getSingleplayerServer()`) and call `Minecraft.getInstance().gui.setScreen(new QuillIdeScreen(session))`.
2. **`ClientEditorSession`**:
   - Preserves open tabs, active tab index, expanded tree paths, and last reload report across screen open/close cycles within the same world session.
3. **`QuillIdeScreen` & `QuillTheme`**:
   - Override `isPauseScreen()` -> `false`.
   - Implement `extractRenderState(GuiGraphicsExtractor graphics, int mouseX, int mouseY, float delta)` with Activity Bar (Explorer view toggle, Presets/Quick Actions toggle), collapsible Sidebar, main Editor Pane, and Status Bar.

**Commit checkpoint**: `feat(client): add keybinding, ClientEditorSession, and non-pausing VS Code screen shell`

---

### Step 4: World & Datapack File Explorer (`src/client`)

**Objective**: Browse `datapacks/` and perform file/folder CRUD directly from the sidebar.

1. **`FileExplorerTreeWidget`**:
   - Displays hierarchical `FileTreeNode` tree starting at `datapacks/` (showing datapacks, `pack.mcmeta`, `data/<namespace>/function/...`, `data/minecraft/tags/function/...`).
   - Expand/collapse folders on click; open files in a tab on click.
   - Context toolbar / row action buttons for:
     - **New File / Folder** inside selected directory
     - **Rename** selected file or folder (with path validation)
     - **Delete** selected file or folder (with confirmation modal)
     - **Refresh Tree**

**Commit checkpoint**: `feat(explorer): implement datapack file explorer tree with open, create, rename, and delete`

---

### Step 5: Quick Actions & Presets UI (`src/client`)

**Objective**: Make creating datapacks, namespaces, `.mcfunction` files, and `data/minecraft` (`load`/`tick`) presets effortless.

1. **Quick Actions Panel & Modal Prompts (`ModalPromptOverlay`)**:
   - **New Datapack**: Prompts for pack folder name and description -> scaffolds `pack.mcmeta` (`min_format: 121, max_format: 121`) + default namespace -> refreshes tree.
   - **New Namespace**: Prompts for target datapack and namespace (`[a-z0-9_.-]`) -> creates `data/<namespace>/function/`.
   - **New `.mcfunction`**: Prompts for datapack, namespace, and function name -> creates and immediately opens the new `.mcfunction` in an editor tab.
2. **Presets Panel**:
   - Lists all presets returned by `EditorBackend.listPresets()` (minimum `#minecraft:load` and `#minecraft:tick`).
   - Clicking a preset prompts for target datapack + namespace (pre-filled from current selection), applies the preset via `EditorBackend.applyPreset(...)`, and opens the generated tag/function in tabs.

**Commit checkpoint**: `feat(ui): add quick action modals and extensible minecraft:load/tick preset UI`

---

### Step 6: Multi-Tab `.mcfunction` Editor, Save & Live Reload (`src/client` & `src/main`)

**Objective**: Full multi-line editing, tab management, `Ctrl+S` save + automatic reload, and clear reload diagnostics.

1. **`EditorTabBarWidget`**:
   - Horizontal scrollable tab strip showing open files.
   - Unsaved dirty indicator (`●`), close button (`×`), middle-click to close, click to switch tab.
2. **`CodeEditorWidget`**:
   - Multi-line text buffer supporting cursor movement (arrows, `Home`, `End`, `PageUp`, `PageDown`, `Ctrl+Left/Right`), text selection (mouse drag + `Shift`+arrows + `Ctrl+A`), clipboard copy/cut/paste (`Ctrl+C`, `Ctrl+X`, `Ctrl+V`), undo/redo (`Ctrl+Z`, `Ctrl+Y`), `Tab` indentation, line numbers gutter, and smooth vertical/horizontal scrolling clipped via `graphics.enableScissor(...)`.
3. **Save & Live Reload Integration**:
   - `Ctrl+S` (or Status Bar "Save & Reload" button) calls `backend.writeFile(path, content, reloadAfterSave = true)`.
   - On completion, clears the tab's dirty indicator and updates the Status Bar:
     - **Success**: Green/Blue status `"Saved & Reloaded (X ms)"`.
     - **Failure / Parse Error**: Red status bar + expandable diagnostics banner showing the offending function/JSON path, line number, and parse error message so the user can jump directly to the broken line.

**Commit checkpoint**: `feat(editor): implement multi-tab code editor with live datapack reload and error diagnostics`
